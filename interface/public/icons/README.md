# Material Symbols

Ícones oficiais de Google Material Symbols, variante Outlined, tamanho 24 px:
`arrow_upward`, `power_settings_new`, `videocam` e `stop`.

Origem: https://github.com/google/material-design-icons/tree/master/symbols/web
Obtidos em 2026-11-09. Licença Apache 2.0 no arquivo LICENSE.
Os paths originais são incorporados como symbols em index.html, mantendo a geometria;
currentColor aplica a cor de interface. Nenhuma fonte ou CDN é necessária em execução.
